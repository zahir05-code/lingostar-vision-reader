# agents-md

## Purpose

This skill creates structured AGENTS.md files
for AI-assisted coding projects.

Use this skill when:
- starting a new project
- organizing multi-agent workflows
- creating coding rules
- documenting project architecture
- improving AI task consistency

---

## Instructions

When invoked:

1. Analyze the project structure
2. Detect frameworks and technologies
3. Identify application goals
4. Generate a clean AGENTS.md file
5. Organize instructions into sections

---

## Required Sections

The generated AGENTS.md must contain:

- Project Overview
- Goals
- Tech Stack
- Folder Structure
- Coding Standards
- Agent Responsibilities
- Workflow Rules
- Constraints
- Output Style

---

## Output Rules

The generated file should:

- use markdown headings
- be concise and structured
- avoid duplicated instructions
- separate global/local rules
- prefer bullet points
- use sequential workflows

---

## Workflow Example

1. Read project files
2. Detect framework
3. Understand architecture
4. Generate AGENTS.md
5. Validate formatting

---

## Best Practices

- Prefer short instructions
- Avoid ambiguity
- Keep workflows explicit
- Use reusable templates
- Separate concerns clearly
