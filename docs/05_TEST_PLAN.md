# 05. Test Plan (LingoStar Vision Reader)

작성일: 2026년 05월 18일
수정일: 2026년 05월 18일

## 1. 테스트 환경
- **Primary Device**: 태블릿 기기 (iPad 10.9" 이상, Galaxy Tab S 시리즈 등)
- **Secondary Device**: 데스크탑 브라우저 (크롬, 사파리)
- **화면 방향**: 주로 가로(Landscape) 및 세로(Portrait) 모드 모두 지원

## 2. 주요 테스트 시나리오

### 2.1 접근성 테스트 (Accessibility)
- **폰트 확대**: 텍스트가 64px까지 확대될 때 UI 깨짐 현상이 없는지 확인
- **터치 영역**: 모든 클릭 가능한 요소가 최소 64px 이상의 터치 타겟을 가지는지 확인
- **대비 및 테마**: 5가지 테마(Light, Dark, Yellow, BlueSoft, HighContrast) 전환 시 글씨가 뭉개지지 않고 선명하게 보이는지 확인

### 2.2 기능 테스트 (Functional)
- **지문 입력**: 15문장 내외의 영문 텍스트 입력 후 정상적으로 문장 단위 분리가 되는지 확인
- **집중 읽기 (Focus Reading)**: 다음/이전 문장으로 부드럽게 넘어가며, 상단 미니맵 바가 정확하게 진행률을 표시하는지 확인
- **청크 읽기 (Chunk Reading)**: 문장이 구/절 단위로 나뉘어 세로 카드 형태로 잘 배치되는지 확인

### 2.3 예외 상황 (Edge Cases)
- 극단적으로 짧은 문장이나 너무 긴 문장이 입력되었을 때의 레이아웃 유지
- 페이지 새로고침 시 로컬스토리지에 저장된 마지막 지문 데이터 복구 여부

## 3. 테스트 진행 방식
- 개발 중: Vite 로컬 서버에서 크롬 개발자 도구의 Device Toolbar 활용
- 배포 전: Vercel/Netlify 프리뷰 링크를 실제 태블릿 기기에서 확인
