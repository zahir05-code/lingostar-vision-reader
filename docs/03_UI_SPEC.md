# 03. UI 명세

작성일: 2026년 05월 18일 17시 00분 00초
수정일: 2026년 05월 18일 17시 00분 00초

## 중요 UX/UI 원칙
1. **단일 핵심 정보**: 한 화면에는 하나의 핵심 정보만 크게 렌더링.
2. **미니맵 고정**: 전체 구조를 잃지 않도록 위치 정보 상단 고정.
3. **거대 버튼**: 태블릿 터치 접근성을 위해 최소 버튼 높이 `72px`, 터치 타겟 `64px` 보장.
4. **라벨 명시**: 아이콘 단독 사용 금지, 텍스트 라벨 병기.

## 화면별 세부 명세
- **HomePage**: 화면 중앙 수직 정렬, 큰 버튼(샘플/새로만들기).
- **PassageInputPage**: 대형 텍스트 영역, 저장 버튼 하단 고정.
- **FocusReadingPage & ClassFollowModePage**:
  - 상단바: "현재 3 / 12 문장 (본론)"
  - 메인: 문장 텍스트 (`font-size` 최소 32px ~ 최대 64px)
  - 보조 영역: 이전/다음 요약 힌트 박스
- **ChunkReadingPage**: 문장을 구/절 단위로 쪼개 세로 리스트형 카드로 나열.
- **SettingsPage**: 스텝퍼를 통한 텍스트 크기 조절, 색상 팔레트를 통한 테마 선택.
