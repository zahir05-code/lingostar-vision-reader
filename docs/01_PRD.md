# 01. 제품 요구사항 문서 (PRD)

작성일: 2026년 05월 18일 17시 00분 00초
수정일: 2026년 05월 18일 17시 00분 00초

## 제품 개요
저시력 학생용 텍스트 집중 및 구조화 읽기 보조 앱

## 핵심 기능 상세
1. **영어 지문 입력**
   - 텍스트 복사/붙여넣기, 제목, 학년 입력
2. **저시력 집중 읽기 모드**
   - 글자 크기 32px ~ 64px 조절
   - 5가지 색상 테마 (light, dark, yellow, blueSoft, highContrast)
   - 줄간격, 글자간격 조절
3. **수업 따라가기 모드**
   - 현재 문장을 초대형으로 노출
   - 이전/다음 힌트 및 미니맵
4. **Chunk 직독직해 모드**
   - 각 문장을 의미 단위(Chunk)로 분해 및 한국어 해석 대응
   - 구문 태그(주어, 동사 등) 제공
5. **문단 구조 압축 모드**
   - 전체를입/본론/결론으로 나누고 각 문단 1줄 요약

## 제외 기능 (MVP Out of Scope)
- 파일/사진 업로드, OCR 기능
- 실제 DB/백엔드 연동, 로그인, 결제
- 실시간 AI 분석 (Mock Data로 대체)

## 저장 방식
- LocalStorage 및 Mock Data 활용
