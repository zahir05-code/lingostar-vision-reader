# 01. 제품 요구사항 문서 (PRD) (LingoStar Vision Reader)

작성일: 2026년 05월 18일 17시 00분 00초
수정일: 2026년 05월 18일 17시 00분 00초

## 제품 개요
저시력 학생용 텍스트 집중 및 구조화 읽기 보조 앱

## 핵심 기능 상세
1. **영어 지문 입력**
   - 텍스트 복사/붙여넣기, 제목, 학년 입력
2. **저시력 집중 읽기 모드**
   - 글자 크기 32px ~ 64px 조절
   - 5가지 색상 테마 (light, dark, yellow, blueSoft, highContrast)
   - 줄간격, 글자간격 조절
3. **수업 따라가기 모드**
   - 현재 문장을 초대형으로 노출
   - 이전/다음 힌트 및 미니맵
4. **Chunk 직독직해 모드**
   - 각 문장을 의미 단위(Chunk)로 분해 및 한국어 해석 대응
   - 구문 태그(주어, 동사 등) 제공
5. **문단 구조 압축 모드**
   - 전체를입/본론/결론으로 나누고 각 문단 1줄 요약

## 제품 범위 확장 및 릴리즈 범위 (Production Release Scope)
- **클라우드 데이터베이스 연동**: Firebase Firestore를 활용하여 실시간 학생의 읽기 위치 및 저장된 영어 지문 데이터를 웹/모바일에 완벽 동기화.
- **다양한 디바이스 배포**: 웹 호스팅(Vercel/Firebase)뿐만 아니라 모바일 디바이스 지원을 위한 패키징 고려.
- **제외 기능**: 결제, 실시간 사진 OCR 및 AI 분석은 추후 업그레이드 범위로 설정하되, 클라우드 DB 연동 및 사용자 인증은 상용화 수준으로 우선 반영.

## 저장 및 데이터 처리 방식
- Firebase Firestore 및 Cloud Storage를 활용하여 사용자 계정별로 데이터 영속성 및 기기 간 동기화를 완전히 지원합니다.
