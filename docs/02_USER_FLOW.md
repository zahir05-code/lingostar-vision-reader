# 02. 사용자 행동 흐름 (User Flow)

작성일: 2026년 05월 18일 17시 00분 00초
수정일: 2026년 05월 18일 17시 00분 00초

## 주요 흐름도

1. **시작 (HomePage)**
   - 앱 진입 -> 앱 목적 안내
   - "새 지문 만들기" 또는 "샘플 지문 열기" 선택

2. **지문 입력 (PassageInputPage)**
   - 영어 지문을 텍스트로 붙여넣고 저장
   - 또는 샘플 불러오기

3. **수업 따라가기 (ClassFollowModePage)**
   - 저장 후 즉시 학습 모드 진입
   - 현재 진행 상태(상단) 및 현재 문장(중앙) 확인
   - 선생님 진도에 맞춰 "이전 / 다음" 버튼 클릭
   - 앞뒤 흐름 확인이 필요할 때 "이전/다음 핵심" 정보 참고

4. **심화 학습 전환 (하단 네비게이션)**
   - "직독직해" -> **ChunkReadingPage**: 구문 단위 구조 확인
   - "구조 보기" -> **ParagraphStructurePage**: 도입/본론/결론 요약 파악
   - "어휘" -> **VocabularyPage**: 주요 단어 확인

5. **설정 및 복구**
   - 톱니바퀴 클릭 -> **SettingsPage**에서 테마/글꼴 변경
   - 중간에 앱을 닫고 다시 열면 가장 최근에 보던 위치로 자동 이동
