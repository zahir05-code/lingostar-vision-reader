# LingoStar MVP 기획 검토서 (PM_Planner)

작성일: 2026년 05월 27일

본 문서는 **LingoStar Vision Reader**의 기획 및 요구사항 타당성을 검토하고, 저시력 보조 웹앱으로서의 핵심 가치를 보장하기 위한 예외 시나리오 및 우선순위를 정의합니다.

---

## 1. MVP 요구사항 요약 및 검토

기존 `docs/01_PRD.md`에 정의된 핵심 기능을 검토하고 구체적인 동작 방침을 정립합니다.

### 1-1. 영어 지문 입력 및 파싱
- **요구사항**: 텍스트 복사/붙여넣기, 제목, 학년 입력
- **PM 검토 의견**:
  - 초보 학생 및 교사가 사용하기 쉽도록 복잡한 파일 첨부 대신 **단순 텍스트 영역(Textarea)**을 제공합니다.
  - 지문이 입력되면, 아키텍처 팀의 유틸리티에 의해 **문장 단위(마침표, 물음표, 느낌표 기준)**로 즉시 쪼개어져 세션 내 배열로 관리되어야 합니다.

### 1-2. 집중 읽기 모드 (Focus Mode)
- **요구사항**: 글자 크기 32px ~ 64px 조절, 5가지 테마, 줄간격/자간 조절, 수업 따라가기(현재 문장 초대형 노출, 미니맵)
- **PM 검토 의견**:
  - 저시력 학생에게 가장 중요한 것은 **시각적 단순화**입니다. 화면 중앙에는 오직 한 문장만 표시하며, 미니맵은 시선을 뺏지 않도록 화면 하단이나 측면에 얇은 막대 형태로 단순하게 노출시킵니다.
  - "이전/다음" 내비게이션 버튼은 화면 하단 좌우에 배치하되, **최소 높이 80px**의 극단적으로 큰 거대 버튼으로 기획합니다.

### 1-3. Chunk 직독직해 모드 (Chunk Mode)
- **요구사항**: 문장을 의미 단위(Chunk)로 분해 및 한국어 해석 대응, 구문 태그 제공
- **PM 검토 의견**:
  - 시야가 극도로 좁은 터널 시야(Tunnel Vision) 학생을 위해, 가로로 긴 문장을 읽는 대신 **구/절 단위로 쪼개어 수직으로 흐르게(Vertical Flow)** 렌더링합니다.
  - 구문 태그(Subject, Verb 등)는 글자 크기 조절에 연동되어 가독성을 해치지 않는 선에서 토글 스위치 형태로 보조 노출되도록 기획합니다.

### 1-4. 문단 구조 압축 모드 (Structure Mode)
- **요구사항**: 도입/본론/결론 분할 및 1줄 요약
- **PM 검토 의견**:
  - 긴 지문을 읽기 전 전체적인 지도를 머릿속에 그릴 수 있도록 돕는 매우 유용한 인지 보조 기능입니다.
  - MVP 단계에서는 정밀한 AI 요약 대신, 입력 화면에서 사용자가 직접 문단별 요약본을 입력하거나, 기본으로 제공되는 단락 요약을 매핑하여 저장해 보여주는 방식을 권장합니다. (추후 업그레이드 범위에 AI 요약 탑재 고려)

---

## 2. 저시력 웹 접근성 (WCAG) 기획 정책
- **화면 깜빡임 방지**: 모드 전환이나 테마 전환 시 화면이 번쩍이지 않도록 부드러운 불투명도(Opacity) CSS 트랜지션을 적용합니다.
- **텍스트 크기 독립성**: 브라우저 돋보기 기능을 사용하지 않고도 웹앱 자체 슬라이더를 통해 모든 글자의 크기가 32px에서 64px까지 동적으로 확대 및 레이아웃 재배열(Reflow)이 되도록 보장합니다.

## 3. 예외 케이스 및 Empty State 시나리오
1. **지문 입력 없이 집중 읽기 진입 시**:
   - "학습할 지문이 비어있습니다. 메인 화면에서 영어 지문을 먼저 입력하거나 기본 샘플 지문을 불러와 주세요."라는 명확한 대형 안내 문구와 [샘플 지문 로드] 버튼을 노출합니다.
2. **잘못된 영문장 기호 입력 시**:
   - 마침표가 전혀 없는 긴 단문 입력 시, 15단어 내외 단위로 강제 줄바꿈 또는 문장 분할 처리를 수행하여 시각적 피로도를 막습니다.
